# eShop
## 📝 Project Overview
Dự án xây dựng nền tảng bán lẻ trực tuyến hiện đại, tập trung vào việc xử lý logic Backend mạnh mẽ với .NET 8.

## 🚀 Technologies
- ASP.NET Core 8
- Entity Framework Core
- SQL Server

## Install packages
- Microsoft.EntityFrameworkCore.Design
- Microsoft.EntityFrameworkCore.SqlServer
- Microsoft.EntityFrameworkCore.Tools

## ✨ Core Features

## 🏗️ Architecture (N-Layer)
Tổ chức theo cấu trúc N-Layer:
1. **API Layer:** Tiếp nhận và điều hướng Request.
2. **Service Layer:** Xử lý logic nghiệp vụ tập trung.
3. **Repository Layer:** Truy cập và thao tác dữ liệu qua EF Core.
